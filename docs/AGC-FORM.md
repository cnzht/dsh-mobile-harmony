## 1. 可本地化基础信息

### 应用介绍（≤ 8000 字，直接粘贴）

```
DSH Mobile 是 DeepSeek Harness（一款开源 AI 编码助手）的 HarmonyOS 移动客户端。

它本身不提供 AI 能力，也不内置服务器，只负责把你「自己部署」的 DeepSeek Harness 服务显示在手机上，让你在手机或平板上继续使用已在电脑端打开的工作区、会话与任务。

【核心功能】
· 扫码连接：电脑端一条命令即可生成带一次性令牌的二维码，手机扫码后自动完成配置
· 手动连接：也可以直接粘贴服务器地址，自由切换多台机器
· 原生会话抽屉：通过 Sessions 按钮快速切换会话、新建会话
· 令牌失效自愈：识别鉴权失效后自动回到配置页并回填地址，无需重新手抄
· 完整 Web 体验：与电脑端一致的会话、轨迹、文件预览等界面
· 连接进度提示：加载过程显示进度层，避免误以为卡死
· 局域网与公网均可：同一 Wi-Fi 直连，或配合隧道在任意网络使用

【适用人群】
已在电脑上使用 DeepSeek Harness 的开发者，希望在手机上随时查看任务进度、继续对话或处理临时需求。

【使用前提】
需要一个可访问的 DeepSeek Harness 服务（由你自行部署在电脑或服务器上）。应用不提供该服务本身，也不包含任何账号体系。

【隐私与安全】
· 不采集设备标识、位置、通讯录、相册等任何个人信息
· 不含统计、广告、推送、崩溃上报 SDK
· 服务器地址与访问令牌仅保存在设备本地
· 所有数据往来只发生在你的设备与你自己的服务器之间

【开源】
本项目为开源软件（MIT License），源码与文档公开在 GitHub，欢迎审阅与反馈。
与 DeepSeek、华为技术有限公司均无隶属、合作或背书关系。
```
