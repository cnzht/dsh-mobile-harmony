### 应用介绍（≤ 8000 字，直接粘贴）

```
Harness Mobile 是开源 AI 编码助手 Harness 的移动客户端。

它本身不提供 AI 能力，也不内置服务器、不内置模型，只负责把你「自己部署」的 Harness 服务显示在手机上，让你在手机或平板上继续使用已在电脑端打开的工作区、会话与任务。


· 扫码连接：电脑端一条命令即可生成带一次性令牌的二维码，手机扫码后自动完成配置
· 手动连接：也可以直接粘贴服务器地址，自由切换多台机器
· 原生会话抽屉：通过 Sessions 按钮快速切换会话、新建会话
· 令牌失效自愈：识别鉴权失效后自动回到配置页并回填地址，无需重新手抄
· 完整 Web 体验：与电脑端一致的会话、轨迹、文件预览等界面
· 连接进度提示：加载过程显示进度层，避免误以为卡死
· 局域网与公网均可：同一 Wi-Fi 直连，或配合隧道在任意网络使用


已在电脑上使用 Harness 的开发者，希望在手机上随时查看任务进度、继续对话或处理临时需求。


需要一个可访问的 Harness 服务（由你自行部署在电脑或服务器上）。应用不提供该服务本身，也不包含任何账号体系。


· 不采集设备标识、位置、通讯录、相册等任何个人信息
· 不含统计、广告、推送、崩溃上报 SDK
· 服务器地址与访问令牌仅保存在设备本地
· 所有数据往来只发生在你的设备与你自己的服务器之间
· 首次启动会弹出隐私政策摘要，同意后方可使用


聊天界面顶栏常驻“AI 生成内容”徽标：会话内容由你自部署的服务生成，本应用仅负责展示。


本项目为开源软件（MIT License），源码与文档公开在 GitHub，欢迎审阅与反馈。
与华为技术有限公司无隶属、合作或背书关系。
```

## 5. 隐私声明

### 管理方式
选择 **使用协议服务（隐私托管）** 或 **自行提供链接**。

### 隐私政策 URL（二选一）

- **推荐（托管）**：用 AGC「协议服务」的标准化模板生成，平台会托管并提供 URL（不依赖 GitHub Pages，最稳）
- **自建**：本仓库已准备 `docs/privacy.html`，启用 GitHub Pages 后使用：
```
https://cnzht.github.io/dsh-mobile-harmony/privacy.html
```
⚠️ 启用方法：仓库 Settings → Pages → Source 选 main 分支 `/docs` 目录，发布后先在无痕窗口打开确认不是 404 再提交。1.0.0 被拒的原因之一就是该链接 404（当时 Pages 根本没开）。

### 用户协议 URL

- 本仓库已准备 `docs/eula.html`，启用 Pages 后：
```
https://cnzht.github.io/dsh-mobile-harmony/eula.html
```

> ⚠️ 若使用自建链接，务必确认页面可直接在浏览器打开（无登录、无跳转、HTTPS）。
