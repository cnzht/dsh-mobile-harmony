# 演示录屏脚本（给审核员看的 60 秒）

目标：让完全不了解项目的审核员，在 60 秒内看懂 **这是什么 → 怎么连 → 连上能做什么**。
全程横屏或竖屏均可，建议**竖屏全屏录制**（手机原生观感）。

> 审核明确要求（1.0.0 驳回第 3 条）：**在 HarmonyOS 设备上录制、从启动应用开始、可完整呈现
> 用户使用核心功能的演示录屏**，上传到 AGC「自测文件」处。备注里写"已附视频"是不够的，
> 必须真的传上去，且录屏要从应用启动开始拍（不要从已连上的会话页开始）。

## 录制前准备（桌面端，5 分钟）

1. 起一个专用演示服务（一次性令牌，录完即弃）：
   ```powershell
   & 'E:\HarmonyOS\scripts\dsh-public-qr.ps1' -Port 3100 -Open
   ```
   记下打印的 `https://xxx.trycloudflare.com/?token=...` 与二维码图片路径。

2. 手机上确认已安装最新 HAP，且**清空过应用数据**（保证从"首启隐私弹窗 → 输入地址"开始）：
   ```bat
   hdc shell bm uninstall cn.cnzht.dshmobile
   hdc shell bm install -p <hap路径>
   ```

3. 关闭手机上无关通知/消息预览，避免录到隐私内容。
4. 录屏：系统自带录屏（下拉控制中心 → 屏幕录制），开启麦克风可选。

## 分镜表（总时长 ≈ 60s）

| # | 时长 | 画面 | 操作 | 字幕（后期加） |
|---|---|---|---|---|
| 1 | 0–5s | 手机桌面 → 点应用图标 | 打开 Harness Mobile，首启隐私弹窗出现 | `Harness Mobile —— 开源 AI 编码助手的移动客户端` |
| 2 | 5–10s | 首启隐私弹窗 | 展示隐私摘要与"隐私政策 / 用户协议"入口，点 **同意** | `首次启动先提示阅读隐私政策，同意后方可使用` |
| 3 | 10–16s | 首页（标题 / 地址输入框 / Connect / Scan QR code / About / 隐私政策链接） | 缓慢展示，手指点一下输入框再收起 | `它本身不提供 AI 服务，只连接"你自己的"服务器` |
| 4 | 16–26s | 电脑屏幕：二维码 | 手机点 **Scan QR code** → 授权相机 → 对准二维码 | `扫码即可完成配置（也支持手动粘贴地址）` |
| 5 | 26–33s | 手机：加载中（转圈 + Connecting…） | 停留展示进度层 | `连接中：显示进度，避免误以为卡死` |
| 6 | 33–41s | 手机：进入 Harness 界面（工作区 / 会话） | 点击"选择工作区"→ 选一个工作区 | `连接成功，直接进入你的工作区` |
| 7 | 41–50s | 会话页（顶栏可见“AI 生成内容”徽标） | 点输入框 → 打一句话（例：`hello`）→ 点发送 → 展示回复开始出现 | `会话内容由你自部署的服务生成，顶栏有 AI 内容标识` |
| 8 | 50–55s | 顶栏 | 点 **Sessions** → 原生会话抽屉展开 → 点 **Close** 收起 | `原生会话抽屉，可快速切换会话` |
| 9 | 55–60s | 点 **i**（About） | 展示开发者/仓库/许可 | `开源项目 · MIT · 开发者（登记名）` |

## 录完后的注意

- 该次录屏使用的 `?token=` 地址录完立即停掉隧道（关闭 cloudflared 进程），
  避免一次性令牌被他人复用：
  ```powershell
  Get-Process cloudflared | Stop-Process
  ```
- 若你在提审说明里承诺"提供临时体验服务器"，请**重新生成一个**新令牌，并确认审核期间保持在线；
  审核结束后再关闭。生成命令：
  ```powershell
  & 'E:\HarmonyOS\scripts\dsh-public-token.ps1' -Port 3100
  ```
