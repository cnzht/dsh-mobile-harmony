# 演示录屏脚本（给审核员看的 60 秒）

目标：让完全不了解项目的审核员，在 60 秒内看懂 **这是什么 → 怎么连 → 连上能做什么**。
全程横屏或竖屏均可，建议**竖屏全屏录制**（手机原生观感）。

## 录制前准备（桌面端，5 分钟）

1. 起一个专用演示服务（一次性令牌，录完即弃）：
   ```powershell
   & 'E:\HarmonyOS\scripts\dsh-public-qr.ps1' -Port 3100 -Open
   ```
   记下打印的 `https://xxx.trycloudflare.com/?token=...` 与二维码图片路径。

2. 手机上确认已安装最新 HAP，且**清空过应用数据**（保证从"输入地址"首页开始）：
   ```bat
   hdc shell bm uninstall com.example.helloharmony
   hdc shell bm install -p <hap路径>
   ```

3. 关闭手机上无关通知/消息预览，避免录到隐私内容。
4. 录屏：系统自带录屏（下拉控制中心 → 屏幕录制），开启麦克风可选。

## 分镜表（总时长 ≈ 60s）

| # | 时长 | 画面 | 操作 | 字幕（后期加） |
|---|---|---|---|---|
| 1 | 0–5s | 手机桌面 → 点应用图标 | 打开 DSH Mobile | `DSH Mobile —— DeepSeek Harness 的移动客户端` |
| 2 | 5–12s | 首页（标题 / 地址输入框 / Connect / Scan QR code / About） | 缓慢展示，手指点一下输入框再收起 | `它本身不提供 AI 服务，只连接"你自己的"服务器` |
| 3 | 12–22s | 电脑屏幕：二维码 | 手机点 **Scan QR code** → 授权相机 → 对准二维码 | `扫码即可完成配置（也支持手动粘贴地址）` |
| 4 | 22–30s | 手机：加载中（转圈 + Connecting…） | 停留展示进度层 | `连接中：显示进度，避免误以为卡死` |
| 5 | 30–38s | 手机：进入 dsh 界面（工作区 / 会话） | 点击"选择工作区"→ 选一个工作区 | `连接成功，直接进入你的 Harness 工作区` |
| 6 | 38–48s | 会话页 | 点输入框 → 打一句话（例：`hello`）→ 点发送 → 展示回复开始出现 | `与电脑端完全一致的会话能力` |
| 7 | 48–54s | 顶栏 | 点 **Sessions** → 原生会话抽屉展开 → 点 **Close** 收起 | `原生会话抽屉，可快速切换会话` |
| 8 | 54–60s | 点 **i**（About） | 展示作者/仓库/许可 | `开源项目 · MIT · 与 DeepSeek、华为无隶属关系` |

## 录完后的注意

- 该次录屏使用的 `?token=` 地址录完立即停掉隧道（关闭 cloudflared 进程），
  避免一次性令牌被他人复用：
  ```powershell
  Get-Process cloudflared | Stop-Process
  ```
- 若你在提审说明里承诺"提供临时体验服务器"，请**重新生成一个**新令牌，并确认审核期间保持在线；
  审核结束后再关闭。生成命令：
  ```powershell
  & 'E:\HarmonyOS\scripts\dsh-public-token.ps1' -Port 3100
  ```
